# Voix

Devenir un meilleur communicant, à son rythme.

Cinq onglets, des fiches courtes. Chaque fiche : la règle en une phrase, puis **Comprendre**, **S'entraîner** (quand c'est utile) et **Au quotidien** (un défi à essayer dans ses vraies conversations).

- **Fond** : organiser ses idées (destination, plan, une idée par phrase, mots-clés, boucler, expliquer un choix, raconter, enseigner).
- **Voix** : note naturelle mesurée au micro, souffle, silence, débit, mots de doute, mélodie, fins de phrase.
- **Corps** : regard, ancrage, mains, visage, écoute, trac.
- **Échange** : répondre d'abord, reformuler, objections, reprendre la main, « je ne sais pas », débattre, poser des questions.
- **Mots** : flashcards de vocabulaire avec répétition espacée (définition → mot, mot → définition, utiliser le mot à voix haute), et fiches de vocabulaire à ajouter au paquet.

Application web statique (HTML, CSS, JS, sans dépendance). Les données restent dans le navigateur.
